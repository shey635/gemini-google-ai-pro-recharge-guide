# Gemini API与Google AI Studio说明

> 核实日期：2026-08-12

Google AI Pro 是个人会员；Gemini API 是开发者调用模型的接口。API Key、项目、账单和用量限制需要在开发者体系内单独管理，购买会员不会自动生成 API Key，也不会自动增加 API 余额。

Google AI Studio 是试用模型、制作原型和管理 Gemini API 开发流程的工具。官方 Google AI Pro 当前列有 AI Studio 扩展限额，但这不代表无限免费API，实际API调用仍适用 Gemini API 条款和计费规则。

星际放映厅当前 Gemini Pro 代充商品明确写明不支持 API 调用、无法使用 AI Studio。购买该商品只能按商品写明的会员服务范围理解，不能用 Google 官方套餐的其他权益作额外承诺。
